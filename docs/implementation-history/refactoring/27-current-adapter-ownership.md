# 27. Accept only the current adapter ownership format

**Executed on 2026-11-24 against `a742637`.** Generation and check require
ownership schema 3 and generator 5 before reading the desired selection. Both
commands return adapter drift (11) when the recorded identity or attribution is
invalid.

## Work

1. In [adapter_contracts.py](../../../src/specromancy_engine/_adapters/adapter_contracts.py)
   set ownership schema 3 and generator 5. Publish one meaning for selection,
   canonical selection input, shared paths and target attribution. Use these
   constants in both the writer and
   [ownership reader](../../../src/specromancy_engine/_adapters/adapter_ownership.py).
   Validate the supported identity before trusting any path. Reject all prior,
   mixed, missing or future identities in generation and check.
2. Remove the single-target path grammar, all-target inference and
   version-specific migration branches. Verify current recorded attribution
   against the recorded selection in both directions. Use today's desired
   selection to compute expected outputs only after establishing ownership.
   Keep unowned collisions, unsafe paths, modified stale files, hash rechecks,
   per-file atomic replacement and manifest-last publication covered.
3. Bootstrap the producer as a reviewed source change. Before switching the
   reader, verify the old generator's check on the producer, including local
   edits. Generate fresh outputs with the new engine in a disposable consumer
   containing only the producer's authored inputs. Compare its path list and
   bytes with the verified producer set, review any removals or conflicts, and
   bring the reviewed generated files and manifest into the checkout together.
   Then run ordinary generation and check again in place. This avoids relying
   on an old manifest for authority after the switch.
4. Replace historical upgrade-success tests with refusal tests and direct
   expectations for current generated bytes. Update the harness compatibility
   reference, installation guide, packaged example tests and distribution checks.
   Document the equivalent fresh-directory path for consumers. Have them preserve
   their original tree, merge authored inputs, generate in a clean destination,
   and review the result before adopting it. Deleting the old manifest alone leaves
   occupied output paths unowned. Editing its version or hashes cannot establish
   ownership.
